# Concert CRM · дизайн-концепция

`GATE: ERROR` — автоматическая проверка в Chrome не завершилась. Consistency не смог проверить ширины 1440 и 390 px, layout checker превысил время ожидания.

Откройте [index.html](index.html) в браузере. Все экраны доступны из меню. В верхней панели есть «Светлая», «Тёмная» и «Как в системе». [Сразу открыть светлую тему](light.html).

Тёмный [скриншот обзора](overview-dark.png) получен в Chrome при ширине 1440 px и просмотрен. Проверка JavaScript прошла для 14 маршрутов, переключателя тем, диалога и фильтра списка. Copy lint прошёл без предупреждений.

В основе концепции — компактная боковая навигация, крупные денежные показатели, таблицы и карточка ближайшего концерта. Navy выделяет навигацию и карточку ближайшего концерта. Оранжевый обозначает главное действие. Рабочие поверхности меняются с белых на графитовые при переключении темы.

Данные и формы демонстрационные. Макет открывается без сети, API и базы данных. Pinterest-референсы использовались для композиции, их изображения в макет не включены.
